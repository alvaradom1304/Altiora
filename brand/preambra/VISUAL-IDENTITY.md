# Identidad visual — PREAMBRA
**Versión:** 1.0 / 2026-11-17 · **Estado:** base visual aprobada como dirección; archivos vectoriales originales de implementación.

## Concepto
El símbolo condensa un **umbral arquitectónico**: el punto de entrada a decisiones mejor fundamentadas. No es una flecha de crecimiento ni una gráfica. La forma se interpreta como portal y monograma abstracto de «P». La idea expresa entrada, criterio y ejecución, sin prometer milagros.

## Logos disponibles
- [Primario sobre obsidiana](logo-primary.svg) — formato horizontal para web, presentaciones y portadas.
- [Isotipo](mark-gold.svg) — avatar, favicon, sello y bordado cuando la reproducción sea suficientemente legible.
- [Monocromático](logo-monochrome.svg) — documentos, impresión a una tinta, tamaños pequeños.
- [Tokens de diseño](tokens.json) — valores para web, UI y piezas editoriales.

Los SVG son **interpretaciones vectoriales originales** basadas en la dirección visual aprobada, no trazados exactos de imágenes generadas. El wordmark utiliza fuentes de sistema de respaldo; para impresión profesional convertir a contornos con la fuente efectivamente licenciada y revisada. No utilizar ® ni afirmar registro de marca sin verificación.

## Paleta
| Token | HEX | Uso |
|---|---|---|
| Obsidiana | `#0B0B0D` | Fondo premium principal |
| Rojo sangre | `#790D19` | Señal de decisión / acento escaso |
| Oro | `#C5A15B` | Monograma, titulares y detalles |
| Piedra | `#E8E3D9` | Texto/fondos editoriales claros |

El oro metálico en mockups es **un efecto de iluminación**: para piezas digitales accesibles usar un oro plano o degradados moderados con contraste suficiente.

## Tipografía
- **Titulares y wordmark:** Cinzel, sujeto a disponibilidad y licencia. Fallback editorial: Georgia.
- **Textos, UI y sistemas:** Montserrat, sujeto a disponibilidad y licencia. Fallback: Arial/sans-serif.
- No adjuntar ni distribuir binarios de fuentes.

## Composición y uso
- Mucho espacio negativo; símbolos grandes en contexto reducido.
- Contraste alto, retículas editoriales, ritmo y fotografía de materiales arquitectónicos.
- El rojo se reserva para una decisión o llamada de atención; el oro, para autoridad y jerarquía.
- En tamaños pequeños usar isotipo sencillo o versión monocromática, no sombras, texturas 3D o brillos.
- La identidad debe funcionar sin mockups cinematográficos: SVG legible, aplicaciones reales y texto accesible.

## Pruebas de publicación
1. Legibilidad en fondo claro y oscuro, y a 24–32 px para isotipo.
2. Contraste WCAG en texto; no usar oro claro para texto fino sobre blanco.
3. Prueba de impresión a una tinta.
4. Exportación de favicon e iconos según soporte.
5. Verificar disponibilidad comercial del nombre, dominios, redes y registro antes de marca pública definitiva.
