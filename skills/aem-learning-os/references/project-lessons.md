# Lecciones por proyecto, con evidencia

Extensión manual del Learning OS inspirada en continuous-learning-v2 de ECC; [procedencia](../../../references/ecc-adoption.json). Reutiliza los handoffs del proyecto. No captura conversaciones, no crea un agente observador y no convierte automáticamente una observación en una regla.

## Ficha mínima
- Proyecto y raíz Git verificados; no deducir identidad del nombre de carpeta.
- Situación concreta que disparó el aprendizaje.
- Acción que funcionó, límites y condiciones en que no debe aplicarse.
- Evidencia: fecha, revisión probada y salida o archivo verificable.
- Intentos fallidos y contraejemplos, sin borrar resultados adversos.
- Estado: hipótesis, observado o revisado. Número de observaciones cuando exista; sin puntuaciones de confianza inventadas.
- Próxima comprobación, responsable y autorización necesaria.

Guardar solo lo necesario en el área de continuidad del proyecto, sin secretos, datos de clientes o transcripciones. Una lección de El Tilichero no pasa a La Central del Queso por compartir herramientas.

## Promoción
Una corrección explícita del usuario conserva su autoridad. Una inferencia del agente requiere revisión y evidencia antes de modificar instrucciones, skills o reglas globales. Comparar primero las capacidades existentes; no crear una skill por cada lección. Aplicar el mismo gate de calidad y seguridad que al resto del catálogo. No iniciar sincronizadores ni tareas programadas.
